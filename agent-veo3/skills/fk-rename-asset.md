# /fk-rename-asset — Standardize Display Names for Images & Videos on Google Flow (mYWVGd)

Skill to automatically or manually rename display names for static images and video clips on the Google Flow Web UI via batch RPC `mYWVGd`.

> *User Reference (Tiếng Việt)*: See [../skills_vi/fk-rename-asset.md](../skills_vi/fk-rename-asset.md) for the Vietnamese documentation.

**Usage:**
- Command: `/fk-rename-asset <asset_id_or_media_id> "<new_title>" [project_id]`
- REST API: `POST http://127.0.0.1:8100/api/flow/video/rename` or `POST http://127.0.0.1:8100/api/flow/image/rename`

---

## 🎯 1. Naming Conventions & Application Rules

### Conditions:
1. **Executing Character Pipelines (`plans/plan_character_pipeline.md`)**:
   - **MANDATORY**: Follow format `[{action} - {camera_angle_deg}] {character_name} - {seq}`.
2. **Explicit User Instruction**:
   - **Always comply 100%** with custom naming formats requested by the user.
3. **No User Request & Outside Pipeline**:
   - Keep default names generated by Google Flow; do not rename arbitrarily.

### Standard Structure:
```
[{action} - {camera_angle_deg}] {character_name} - {seq}
```
- `{action}`: Concrete motion (e.g., `walking`, `idle breathing`, `sword slash`, `sprint`, `ready stance`, `standing`).
- `{camera_angle_deg}`: Camera view angle in degrees (e.g., `0`, `45`, `90`, `135`, `180`, `225`, `270`, `315`).
- `{character_name}`: Character or entity name (e.g., `Luna`, `Commander`, `Warrior`).
- `{seq}`: 2-digit generation sequence number (`01`, `02`, `03`...).

### 🎬 Examples for Video:
- `[walking - 45] Luna - 01` *(45-degree walking clip, 1st gen)*
- `[idle breathing - 0] Luna - 01` *(Frontal 4s idle loop clip)*
- `[sword slash - 90] Warrior - 01` *(Profile 90-degree combat slash)*

### 📸 Examples for Static Images:
- `[standing - 0] Luna - 01`
- `[ready stance - 45] Warrior - 01`

---

## ⚡ 2. Execution Methods

### Method 1: Auto-Rename on Generation (Recommended)
When invoking `/api/flow/generate-image` or `/api/flow/generate-video`, include `"title"` (or `"display_name"`). The backend automatically triggers RPC `mYWVGd` immediately after task dispatch:

```bash
curl -X POST http://127.0.0.1:8100/api/flow/generate-video \
  -H "Content-Type: application/json" \
  -d '{
    "start_image_media_id": "<IMAGE_MEDIA_ID>",
    "end_image_media_id": "<IMAGE_MEDIA_ID>",
    "prompt": "seamless idle loop, martial arts stance, green background #00FF00",
    "duration_s": 4,
    "project_id": "<PID>",
    "title": "[walking - 45] Luna - 01"
  }'
```

### Method 2: Post-Creation Rename Endpoint
Rename existing assets generated from batch `/api/requests/batch` or external scripts:

1. **Rename Video**:
```bash
curl -X POST http://127.0.0.1:8100/api/flow/video/rename \
  -H "Content-Type: application/json" \
  -d '{
    "asset_id": "<VIDEO_OPERATION_OR_MEDIA_UUID>",
    "title": "[walking - 45] Luna - 01",
    "project_id": "<PID>"
  }'
```

2. **Rename Image**:
```bash
curl -X POST http://127.0.0.1:8100/api/flow/image/rename \
  -H "Content-Type: application/json" \
  -d '{
    "asset_id": "<IMAGE_ASSET_OR_MEDIA_UUID>",
    "title": "[standing - 0] Luna - 01",
    "project_id": "<PID>"
  }'
```

> **Smart Resolution**: You can pass media UUIDs directly; `resolve_asset_id` locates the corresponding node in the project graph and updates it reliably.
